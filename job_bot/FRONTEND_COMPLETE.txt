================================
🔌 API ENDPOINTS
================================

POST   /api/search                  - Start new search
GET    /api/search/progress         - Real-time progress
GET    /api/results                 - Get all jobs
GET    /api/results/{id}            - Get job detail
GET    /api/results/{id}/cover-letter - Get cover letter
POST   /api/results/{id}/apply      - Mark as applied
DELETE /api/results/{id}            - Delete result
GET    /api/config                  - Get configuration
GET    /api/stats                   - Get statistics

Full docs: http://localhost:8000/docs

================================
📥 INSTALLATION
================================

1. Install Python dependencies:
   pip install -r requirements.txt

2. Install Node dependencies:
   cd frontend && npm install

3. Start both servers:
   # Terminal 1:
   python backend/app.py
   
   # Terminal 2:
   cd frontend && npm run dev

4. Open http://localhost:3000
